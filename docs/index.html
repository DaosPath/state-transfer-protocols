Research path

From discovery to live repository validation

EXP10 represents the culmination: the protocols are tested through a public web/repo artifact, not only judged as isolated text.

EXP05

Discovery at Scale

Broad multilingual, multi-model evaluation across natural, compressed, hybrid_min, and hybrid_state.

Outcome: signal found
EXP06

Controlled Protocol Test

Paired compressed vs hybrid_state under controlled language and tokenizer variants.

Outcome: tradeoff confirmed
EXP07 / EXP08

Real-Agent Validation

LangGraph/OpenFang-style handoffs with objective validators, then larger scale-up.

Outcome: objective pressure
EXP09

Tool-Use Validation

Controlled file-level tasks with deterministic validators for CSV, JSONL, tables, manifests, and claims.

Outcome: interface hardened
EXP10

Public Repo Agent

Tool-using agent edits public artifacts while preserving constraints, claims, dependencies, and recovery.

Outcome: 64/64 Gemini OK
EXP11

Page Task Assignment

Gemini 3.5 Flash and Azure GPT-5.4 High maintain the public page through assigned design/content tasks.

Outcome: 83/96 real model OK
EXP13

Scientific Repo Benchmark

Role-conditioned agents maintain scientific repo artifacts with objective validators for claims, scope, dependencies, security, and HTML integrity.

Outcome: 126/128 real model OK
EXP15-B

Visual Responsive Scale-Up

Long-horizon public-page maintenance stress test across Gemini, GLM, Qwen, Grok Reasoning, and Grok Non-Reasoning.

Outcome: 1204/2000 strict cells OK

Core finding: compressed is the universal operational baseline; hybrid_state is specialized for explicit state transfer but can expose contract fragility in longer role-conditioned tasks.

EXP15/EXP15-B: long-horizon visual maintenance

Cross-cultural page editing as a contract-compatibility stress test

EXP13: main scientific-repo benchmark

Controlled multi-agent maintenance with objective validators

EXP13 assigns each task to a simulated team: writer, reviewer, reproducibility, security/claims, and merge/repair agents. The artifact is a scientific repository page. The validator checks claim preservation, scope drift, dependency preservation, secret safety, local-path leakage, responsive integrity, and whether real file edits occurred.

Real model cells 126/128

Two final failures were retained as evidence: one Gemini JSON-contract failure and one Azure no-change failure.

EXP11: assigned page maintenance

Protocol effects become visible under constrained web-editing tasks

EXP11 uses the existing GitHub Pages site as the artifact. Agents receive scoped tasks such as adding result summaries, improving responsive layout, protecting claims, and preserving links. Validators check HTML integrity, scope drift, claim drift, mobile readiness, external dependency freedom, and secret safety.

Hybrid_state helped the smaller model: compressed reached 14/24 OK, while hybrid_state reached 21/24 OK.

The higher-budget model completed both modes, suggesting model capacity can compensate for weaker protocol structure.

Reproduce

One experiment line, deterministic checks

EXP10 starts with public-repo tasks. EXP11 extends it with assigned page-maintenance tasks. EXP13 controls scientific-repo roles. EXP15/EXP15-B scale long-horizon visual and responsive maintenance.

python run_exp10_resumable.py --preflight
python run_exp10_resumable.py --dry-local --reps 2
python status_exp10.py
python validators/validate_public_repo_case.py --task-bank task_bank_exp10_seed.jsonl --task-id T001 --repo workspace_runs/T001__hybrid_state__rep1

python run_exp11_resumable.py --preflight
python run_exp11_resumable.py --model-route gemini_3_5_flash --reps 2
python run_exp11_resumable.py --model-route azure_gpt_5_4_high --reps 2

Strong claims

  • compressed is a robust universal operational compression baseline.
  • hybrid_state is specialized for explicit state and continuity preservation.
  • objective validators reduce dependence on LLM-as-judge.
  • EXP11 suggests hybrid_state improves reliability for smaller page-maintenance agents.
  • EXP13 shows compressed was more operationally robust in role-conditioned scientific-repo maintenance.
  • EXP15-B shows later page-maintenance tasks are sensitive to model/tool contract compatibility.

Do not claim

  • hybrid_state wins globally.
  • ZH proves tokenization advantage.
  • universal agent interoperability is proven.
  • model rankings are general capability results.
  • EXP11 proves general web-agent superiority.
  • EXP13 proves arbitrary repository maintenance is solved.
  • EXP15-B is a general visual-design benchmark or aesthetic ranking.
