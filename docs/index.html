Research path

From discovery to live repository validation

EXP10 represents the culmination: the protocols are tested through a public web/repo artifact, not only judged as isolated text.

EXP05

Discovery at Scale

Broad multilingual, multi-model evaluation across natural, compressed, hybrid_min, and hybrid_state.

Outcome: signal found
EXP06

Controlled Protocol Test

Paired compressed vs hybrid_state under controlled language and tokenizer variants.

Outcome: tradeoff confirmed
EXP07 / EXP08

Real-Agent Validation

LangGraph/OpenFang-style handoffs with objective validators, then larger scale-up.

Outcome: objective pressure
EXP09

Tool-Use Validation

Controlled file-level tasks with deterministic validators for CSV, JSONL, tables, manifests, and claims.

Outcome: interface hardened
EXP10

Public Repo Agent

Tool-using agent edits public artifacts while preserving constraints, claims, dependencies, and recovery.

Outcome: 64/64 Gemini OK

Core finding: compressed is the universal baseline; hybrid_state is specialized for preserving state, constraints, and claims in real agent handoffs.

Reproduce

One experiment, deterministic checks

EXP10 starts with 16 tasks, 2 modes, 2 repetitions, and explicit long-chain tasks. The final Gemini run completed 64/64 latest cells.

python run_exp10_resumable.py --preflight
python run_exp10_resumable.py --dry-local --reps 2
python status_exp10.py
python validators/validate_public_repo_case.py --task-bank task_bank_exp10_seed.jsonl --task-id T001 --repo workspace_runs/T001__hybrid_state__rep1

Strong claims

  • compressed is a robust universal operational compression baseline.
  • hybrid_state is specialized for explicit state and continuity preservation.
  • objective validators reduce dependence on LLM-as-judge.

Do not claim

  • hybrid_state wins globally.
  • ZH proves tokenization advantage.
  • universal agent interoperability is proven.
  • model rankings are general capability results.
