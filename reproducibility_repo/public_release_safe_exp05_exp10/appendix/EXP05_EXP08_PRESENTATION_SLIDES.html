EXP05-EXP08

Symbolic Compression Protocols for Multi-Agent Handoff

Core claim: compact protocols can be evaluated as operational state-transfer mechanisms, not just prompt compression tricks.

Problem

Agents lose continuity when context is compressed, multilingual, transferred across models, or handed to another framework.

Question: can compact protocols preserve enough state for another agent to continue work?

Protocols

  • natural: normal prose
  • compressed: compact operational notes
  • hybrid_min: extreme symbolic compression
  • hybrid_state: compact structured state handoff

EXP05: Broad Discovery

ES / EN / ZH, multiple model families, four protocol modes, LLM-judge metrics.

Finding: compressed was the strongest universal baseline; hybrid_state showed early continuity signal.

EXP05: Multilingual Signal

ZH did not collapse under compression and sometimes scored better.

Interpret as promising evidence for language/tokenization effects, not proof.

EXP06: Controlled Test

compressed vs hybrid_state under stricter causal transfer controls.

Variants: ES, EN, ZH, ZH_PINYIN, EN_LITERAL, ES_LITERAL.

EXP06: Tradeoff

hybrid_state improved state-oriented transfer in selected conditions, but did not dominate global quality.

Interpretation: compressed baseline; hybrid_state specialized for operational state.

EXP07: Real-Agent Handoff

Frameworks

  • LangGraph-style
  • OpenFang-style

Objective metrics

  • variable recovery
  • subtask completion
  • plan continuity
  • constraint retention

EXP07: Objective Result

compressed remained operationally robust. hybrid_state showed narrower advantages around explicit state and constraint retention.

EXP08: Scale-Up

30 tasks, 5 repetitions, 2 frameworks, 2 Azure model routes for LangGraph, 900 expected executions.

Goal: test whether EXP07 patterns survive larger sampling.

Reproducibility and Safety

  • paper source and figures
  • appendix and task banks
  • aggregate CSVs
  • redacted JSONL dataset
  • manifests, checksums, security sweep

Takeaway

Strong: compressed is a universal operational compression baseline.

Careful: hybrid_state is a specialized protocol for state/continuity, not a universal quality winner.
