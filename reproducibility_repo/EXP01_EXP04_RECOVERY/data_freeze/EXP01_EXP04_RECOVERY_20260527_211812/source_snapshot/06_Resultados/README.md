# Resultados

## Proposito

Guardar resultados reales de experimentos, tablas comparativas, observaciones y conclusiones parciales.

## Contenido principal

Esta carpeta no debe mezclar resultados esperados con resultados reales. Si una prueba no se ejecuto, se marca:

```txt
PENDIENTE_DE_EJECUCION
```

## Archivos

- `Tabla_Resultados_Template.md`: tabla base para registrar mediciones.
- `Observaciones_Iniciales.md`: observaciones esperadas sin presentarlas como datos.
- `Conclusiones_Parciales.md`: estructura para conclusiones cuando existan resultados.

## Riesgos o limitaciones

- Inventar resultados invalida la investigacion.
- Conclusiones sin tokenizer o prompt no son reproducibles.
