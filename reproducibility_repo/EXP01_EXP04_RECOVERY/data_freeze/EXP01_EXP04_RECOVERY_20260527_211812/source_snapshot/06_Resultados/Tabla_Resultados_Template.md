## Campos adicionales recomendados

| Campo | Uso |
|---|---|
| Tokenizer | Necesario para reproducir conteos. |
| Temperatura | Controla variacion de salida. |
| Fecha | Ubica version del experimento. |
| Prompt ID | Vincula resultado con prompt exacto. |
| Evaluador | Humano, agente o mixto. |

## Riesgos o limitaciones

- La tabla no reemplaza notas cualitativas.
- La calidad debe evaluarse con rubrica definida.
